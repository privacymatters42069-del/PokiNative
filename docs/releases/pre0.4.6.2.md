# PokiNative pre0.4.6.2

This is a public test prerelease for the upcoming 0.4.6.2 launcher. The Windows and Linux launchers report version 0.4.6.2.

Download the Windows launcher or Linux AppImage from this page and install it separately from the stable launcher. This prerelease is intended for testing and may contain bugs; it does not change the stable 0.4.6.1 release.

The prerelease is published by GitHub Actions only after repository validation and both launcher builds succeed.
